## 提交前匿名检查

- PPT/视频/演示页不出现学校、单位、成员姓名、Logo、水印。
- 检查 PPT 属性、视频片尾、演示账号昵称、二维码。
- 演示账号使用 `judge_demo`，不绑定真实个人信息。
- 材料中的用户故事、访谈引语全部匿名化。
- 不上传 `.env`、`*.db`、真实密钥和真实用户数据。
