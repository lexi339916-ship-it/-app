## 1. 审查结论（先说重点）

项目主体已经可运行，三英雄场景、审批/撤销/审计、主动扫描、语音转写接口都有真实代码和测试支撑。但距离“比赛级可信 Agent”仍有四个硬缺口：

1. **没有消费健康诊断**：预算、目标、订阅、结构、计划五类信息散落在多个页面，没有统一公式和报告。
2. **主动预警覆盖不足**：缺少目标延期、消费行为变化、异常大额的统一通知；忽略后永不提醒；通知文案和金额影响不规范。
3. **评测不够硬**：原 60 条评测只查状态/关键词，没有参数准确率、审批一致性、数据库回查、并发、拒绝、撤销、异常注入等严格断言。
4. **交付安全未闭环**：`backend/.env` 有真实密钥，多个 `*.db` 在项目根目录；Docker 未安装、公网地址未验证。

本轮已完成上述 1–3 的代码改造，并补了登录限流、敏感信息脱敏、交付检查脚本；第 4 项中“删除密钥/数据库、轮换密钥、公网部署”需要人工在提交前完成。

## 4. 本轮修复的真实缺陷

1. **中文数字错误**：`一百二` 被算成 102、`十五块五` 只取 15。
   已重写 `_cn_to_int` 与金额小数解析，新增 56 项断言。
2. **目标周期不支持中文**：`三个月/两年` 无法解析。
   已支持中文月/年，并补测试。
3. **“计划一下”被当成 1 元**：口语“一下/一点/一起”被当作金额。
   已加入噪声词过滤，缺金额时正确澄清。
4. **中文金额被路由到查询**：`咖啡十五块五` 不进入记账。
   已补中文金额意图识别。
5. **“预算”一词劫持多步任务**：`3个月存3000…顺便看看预算` 被当成查询。
   已调整意图优先级，多步任务恢复到目标/记账场景。
6. **敏感信息只脱敏数字**：`密码是 abc123` 会进入响应。
   已改为密码/验证码/卡号后的字母数字组合统一打码，并验证不进入审批 diff。
7. **预算刚好 100% 被说成“超支 0 元”**：新增 `used_up` 状态，区分“刚好用完”和“真正超支”。
8. **健康分覆盖不足仍给“优秀”**：覆盖率 <50% 时不再给总分，显示“数据不足”。
9. **健康报告把当前目标/订阅用于历史空月份**：按创建时间过滤，避免时间穿越。
10. **测试时间炸弹**：`2026-12-01` 固定未来日期改为相对日期。

## 5. 新增功能与接口

### 5.1 消费健康诊断

`GET /api/consumption-health/report?month=YYYY-MM`

- 收支：收入、支出、结余、结余率、日均、预计月支出、环比。
- 分类：金额、占比、环比、预算、使用率、状态。
- 预算：总额、已花、剩余、使用率、超支/用完/接近上限数量、未设预算支出。
- 目标：进度、目标日、每月需存、预计完成、延期天数、状态。
- 订阅：进行中数量、月固定支出、本月扣费、占比、涨价/低频/重复问题。
- 变化：分类环比明显变化、异常大额。
- 五项指标：预算执行 30%、储蓄目标 25%、订阅健康 15%、结构稳定 15%、计划执行 15%。
- 每项指标返回 `formula / inputs / source / period / as_of / explanation`。
- 数据不足返回 `available=false`，不惩罚用户。
- 免责声明：不是信用评分、金融风险评级或投资建议。

### 5.2 主动预警补强

覆盖：预算超支、预算用完、接近上限、订阅涨价/低频/重复、目标延期/停滞、消费分类变化、总支出变化、异常大额、计划采购。

每条通知包含：标题、等级、触发原因、关联数据、金额影响、建议、时间、状态。
去重规则：同用户同 dedupe_key 只保留一条；忽略后冷却 7 天，最多再提醒 2 次；风险升级（如接近上限→超支）重新变未读。

### 5.3 多轮对话最小可用版本

- `agent_runs` 新增 `session_id / parent_run_id / turn_index`；同一 session 内审批独立。
- 新增 `GET /api/agent/sessions`、`GET /api/agent/sessions/{session_id}`。
- 追问支持：换预算来源（“不想动 X”）、改调配金额（“只调整 N 元”）、选择替代方案（“选择第二种”）。
- 旧审批标记 `superseded`，不能重复执行；新方案重新走审批。
- 前端 Agent 页增加“本轮对话”线程、追问示例、新对话按钮。

### 5.4 消费决策模拟器

`POST /api/decision-simulator/simulate`

- 输入：金额、分类、目标、观察周期。
- 输出：分类预算剩余/超支、购买后本月结余、目标差额 before/after、预计完成时间、截止日延期、完成时间额外延后。
- 三种方案：现在购买、下月购买、分 N 个月压缩其他支出。
- 缺近 3 月账单 / 缺目标 / 缺分类预算时返回 `missing`，不猜。
- 明确声明：不代表账户真实余额，不构成投资建议。

### 5.5 CSV 账单导入

`POST /api/imports/preview`、`POST /api/imports/preview-file`、`POST /api/imports/confirm`

- 支持通用表头、微信/支付宝常见表头、UTF-8/GBK、5MB/5000 行上限。
- 解析日期、金额、收支类型、分类、渠道、扣款账户；无法识别的行进入错误列表。
- 已有账单 + 文件内双重去重；确认后写入 `source=csv`。
- 前端支持粘贴文本或选择 CSV 文件、逐行勾选、确认导入和结果汇总。

### 5.6 评测硬化

- `tests/agent_eval/cases.py`：100 条，dev/test 各 50。
- `run_eval.py`：任务成功率、工具选择、参数、金额一致性、审批一致性、禁止内容、未审批写入、延迟、成本、解析来源。
- `run_flow_eval.py`：94 项数据库级断言，覆盖审批/拒绝/替代方案/编辑/过期/并发/回滚/模型异常/工具失败/跨用户/空库/注入。
- 报告：`report.md`、`report_test.md`、`flow_report.md`。

- **Docker**：本机未安装，`docker compose up` 未实跑。
- **视频录制**：脚本已更新，真实录屏未录制。
- **用户验证**：5–8 名真实用户测试未执行，不能编造。
- **报名/缴费**：外部系统操作，未执行。

### 结论

代码侧 P0 与可自动化的外部 P0（JWT、交付包、PPT、临时公网验证、部署脚本）已完成；稳定公网、AI Key、Docker、视频、用户测试和报名仍需要外部账号/服务器/真人参与。
