# 3 分钟现场演示脚本

## 演示前 5 分钟检查

```bash
# 1. 重置演示数据（可重复执行）
python tools/seed_demo.py

# 2. 确认后端健康
curl http://127.0.0.1:8000/api/agent/health

# 3. 打开 H5
# http://127.0.0.1:8080
# 账号：judge_demo / judge2026
```

- 关闭订阅提醒弹窗（点“知道了”）。
- 打开底部 **Agent** Tab，确认页面无旧任务。
- 准备两个浏览器标签：Agent 页、账单页（用于展示写入结果）。
- 准备离线备用视频和 `deploy/h5` 预构建产物。

## 3 分钟流程

### 0:00–0:20 开场

“这是知账，一个面向大学生和初入职场人群的家庭消费健康 Agent。不是只记账，而是把记账、预算、订阅、目标串成可审批的行动闭环。今天演示三个真实任务。”

### 0:20–1:20 场景 1：记账 → 预算 → 审批 → 撤销

1. 输入：`午饭花了32元，微信付的`，点“运行 Agent”。
   - 如果已配置 ASR，可先按住“按住说话”说“午饭三十二”，展示语音转文字；未配置就直接输入文字，不假装语音可用。
2. 指出：执行计划 5 步、工具轨迹、审批卡。
3. 读出关键数字：“餐饮已花 1180 / 预算 1200，这笔会超 12 元；从交通调配 50 元，并创建本周控制餐饮任务。”
4. 点“批准执行”。
5. 切到账单页，展示新增账单；回到 Agent 页，展示“已完成、可撤销”。
6. 点“撤销上一次执行”，说明数据恢复。

**讲解点**：写操作先出 diff，用户批准才执行；审批幂等、可撤销、可审计。

### 1:20–2:10 场景 2：订阅体检 → 拒绝 → 重规划

1. 输入：`帮我检查一下订阅，看看有没有涨价或低频的`。
2. 指出：视频会员 25→30 且近 90 天只用 1 次；健身会员 90 天 0 次，合计年化影响约 ¥2748。
3. 点“先不要”（拒绝暂停）。
4. 指出：Agent 生成替代方案“先观察一个月”，并创建复盘任务；不是重复原方案。
5. 点“批准执行”，展示任务创建。

**讲解点**：human-in-the-loop；拒绝后重规划；不自动取消第三方订阅，只做站内状态和提醒。

### 2:10–2:50 场景 3：目标规划

1. 输入：`3个月存3000元去旅行`。
2. 指出：近 3 个月平均结余、每月需存 1000、可行性判断。
3. 指出：餐饮/购物/娱乐预算压缩约 540 元，创建旅行基金和每周复盘任务。
4. 点“批准执行”，展示目标创建。
5. 说明：一周后 Agent 会对比实际 vs 计划，偏离时重规划。

### 2:50–3:00 收尾

“每个数字来自 SQL，每个写操作要审批，执行后可撤销。我们希望每个普通家庭都有一个看得懂、敢交给它办事的消费健康 Agent。”

## 评委追问时的现场演示

- **“这是不是规则？”** 换一个输入，例如“打车回家 21 块，支付宝”，展示解析和审批变化；再问“我有几个订阅”“这个月最大支出”，展示不同工具。
- **“数字哪来的？”** 打开账单页对照，或展示 trace 里的 `source` / `as_of`。
- **“模型挂了怎么办？”** 断开 AI 配置或模拟 503，展示规则降级和“改用文字/手动记账”。
- **“拒绝审批会怎样？”** 演示订阅拒绝 → 替代方案。
- **“重复批准会重复写吗？”** 再点一次批准（若按钮仍可点），说明幂等；或展示 `tests/agent_smoke.py` 的重复批准断言。
- **“能撤销吗？”** 点撤销，回账单页确认删除。

## 兜底方案

| 故障 | 处理 |
|---|---|
| 网络/后端挂了 | 切离线录屏；说明本地 Docker 一键启动 |
| AI 超时 | Agent 自动规则降级；或换“查询”模式演示 |
| 数据被改乱 | `python tools/seed_demo.py` 重置 |
| H5 打不开 | 用 `deploy/h5` 静态站或直接展示后端 `/docs` + 录屏 |
| 评委要求换数据 | 用种子脚本重新生成，或现场手动记一笔 |
