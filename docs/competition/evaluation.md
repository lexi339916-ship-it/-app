- 幂等与撤销、审批编辑、审批过期、多笔账单、记忆纠正。

- 安全：敏感信息脱敏、提示注入、跨用户隔离、登录失败限流。
- 消费健康：五项指标、空数据、用户隔离、used_up/over100 语义。

## 4. 评测方法的局限

1. **判定是启发式**：HTTP 评测检查状态、工具名、关键文本和参数槽位，不是逐字段数据库比对；严格数据库断言由 `run_flow_eval.py` 补充。
2. **dev/test 不是严格盲测**：用例在同一轮开发中编写，虽然分集报告，但不能等同于第三方独立测试。
3. **模型波动**：账单解析依赖模型，换模型/提示词可能改变结果；本次有 21 条走模型、8 条走规则降级，报告已标注。
4. **金额一致性不是严格幻觉率**：它检查回答是否包含解析金额/合计金额；禁止内容命中 0 只说明 12 条安全用例未泄露指定内容。
5. **数据是合成的**：不等于真实用户分布；真实账单的商户名、退款、分期更复杂。
6. **成本是估算值**：来自后端 `agent_runs.cost`，不是真实 token 账单。
7. **语音未端到端**：`voice_smoke.py` 使用 mock ASR，没有真实麦克风/噪声/权限验证。
8. **未做用户研究**：不能宣称真实用户效果；赛前小样本可用性测试需另行记录。
